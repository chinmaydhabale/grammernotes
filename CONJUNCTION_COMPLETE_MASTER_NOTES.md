## 1. Conjunction Definition & Core Function

### 🔍 Conjunction kya hota hai?
- **Definition**: Conjunction ek aisa **Connecting / Joining Word** hota hai jo:
  1. Do shabdon (**Words**) ko jodta hai → *Ram **and** Shyam are friends.*
  2. Do vakyanshon (**Phrases**) ko jodta hai → *In the room **or** on the terrace.*
  3. Do up-vakyashon (**Clauses / Sentences**) ko jodta hai → *He worked hard **but** he failed.*
- **Key Function**: Yeh sentences ko concise (chhota) aur logically connected banata hai bina unke meaning ko badle.

---

### 📊 Master Classification of Conjunctions:

```
                               ┌────────────────────────────────────────┐
                               │              CONJUNCTIONS              │
                               └───────────────────┬────────────────────┘
                                                   │
                ┌──────────────────────────────────┼──────────────────────────────────┐
                ▼                                  ▼                                  ▼
      【 COORDINATING 】                 【 SUBORDINATING 】                【 CORRELATIVE 】
      • Equal rank ke clauses ko         • Dependent clause ko              • Pairs (jodon) me aane
        jodte hain (FANBOYS):              Independent clause se jodte        wali conjunctions:
        For, And, Nor, But, Or, Yet, So    hain: Because, Since, As,          Either...or, Neither...nor,
      • Independent clauses                If, Unless, Until, Although        Not only...but also, Both...and
```

## 2. The "Suppose" vs. "If" Superfluous Error

Tarun Grover sir ka **"Redundancy Elimination" Concept**:

```
                         ┌────────────────────────────────────────┐
                         │           SUPPOSE vs. IF TRAP          │
                         └───────────────────┬────────────────────┘
                                             │
               ┌─────────────────────────────┴─────────────────────────────┐
               ▼                                                           ▼
     【 "SUPPOSE" = मान लो / यदि 】                               【 "IF" = अगर / यदि 】
     • Dono shabdon ka arth ek hi hota hai                       • Dono ka prayog shart (condition) ya
     • Inhe EK SATH prayog karna bilkul GALAT hai!                 kalpana darshane ke liye hota hai.
     • Formula: Ya to `SUPPOSE` lagao, YA `IF` lagao!            • `Suppose if...` ❌ (Superfluous!)
```

---

### 🚫 The "Suppose If" Cardinal Trap:
- **Rule**: Sentence me `Suppose` aur `If` (ya `Supposing` aur `If`) kabhi ek sath nahi aate. Dono me se kisi ek ko hatana padta hai.

| Incorrect Sentence (Common Exam Error ❌) | Correct Sentence (Standard English ✅) | Grammatical Reason |
| :--- | :--- | :--- |
| *Suppose if you see ghosts, what will you do?* | *Suppose you see ghosts, what will you do?*<br>*(या)* *If you see ghosts, what will you do?* | *Suppose* aur *if* ek sath aana superfluous (अनावश्यक) hai. |
| *Supposing if you become a Bank PO in the next few months, what will you do?* | *Supposing you become a Bank PO in the next few months, what will you do?* | *If* ko remove karo. |
| *Suppose if the flight is delayed, we will inform you.* | *If the flight is delayed, we will inform you.* | *Suppose* ko remove karo. |

## 3. The "Lest ... Should" Master Rule

Exam ka **one of the highest frequency rules**:

```
                  ┌───────────────────────────────────────────────────────────┐
                  │                THE "LEST ... SHOULD" RULE                 │
                  └─────────────────────────────┬─────────────────────────────┘
                                                │
                ┌───────────────────────────────┴───────────────────────────────┐
                ▼                                                               ▼
      【 1. FIXED PAIR: LEST ... SHOULD 】                            【 2. INHERENT NEGATIVE: NO "NOT" 】
      • `Lest` ke sath aane wala model auxiliary                      • `Lest` ka arth hi hota hai:
        hamesha **"SHOULD"** hi hota hai!                               "ऐसा न हो कि / कहीं ऐसा न हो जाए / ताकि न"
      • `Will, Would, May, Might, Can, Could`                         • Iske sath **"NOT" lagana STRICTLY PROHIBITED**
        lagana 100% PROHIBITED hai!                                     hai (Double Negative Error)!
```

$$\mathbf{Lest\ +\ Subject\ +\ SHOULD\ +\ V1\ (Base\ Form)\ \ \ \ [Strictly\ NO\ "NOT"]}$$

---

### 📝 Examples & Exam Traps:
1. *Walk carefully lest you should hurt yourselves.* ✅
   - *Error*: *Walk carefully lest you **should not hurt** yourselves.* ❌ (Never use *not* after lest!).
   - *Error*: *Walk carefully lest you **will / may hurt** yourselves.* ❌ (Must use *should*!).
2. *Run fast lest you should miss the train.* ✅
   - *Error*: *Run fast lest you **might miss** the train.* ❌
3. *Hurry up lest you should be late for the examination.* ✅
4. *You should not be so hasty in giving advice lest you **should be perceived** as interfering in other people's work.* ✅

## 4. "Doubt" & "Doubtful" Rules

Tarun Grover sir ka **"Sentence Nature" Master Logic**:

```
┌────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│                              "DOUBT" & "DOUBTFUL" USAGE MATRIX                                        │
├──────────────────────────┬─────────────────────────────┬───────────────────────────────────────────────┤
│ Sentence Nature          │ Meaning / Psychological State│ Connecting Conjunction                       │
├──────────────────────────┼─────────────────────────────┼───────────────────────────────────────────────┤
│ **AFFIRMATIVE (+ve)**    │ **Uncertainty / Suspicion** │ **`IF`** / **`WHETHER`**                      │
│ (Positive sentence)      │ (Shak hai, pakka pata nahi) │ • *I doubt IF / WHETHER he will pass.*        │
│                          │                             │ • *She is doubtful IF / WHETHER they agree.*  │
├──────────────────────────┼─────────────────────────────┼───────────────────────────────────────────────┤
│ **NEGATIVE (-ve)**       │ **Certainty / Sureness**    │ **`THAT`**                                    │
│ (not, never, no doubt)   │ (Koi shak nahi, baat pakki) │ • *I do NOT doubt THAT he will pass.*         │
│                          │                             │ • *There is NO doubt THAT honesty pays.*      │
├──────────────────────────┼─────────────────────────────┼───────────────────────────────────────────────┤
│ **INTERROGATIVE (?)**    │ **Asking for Fact**         │ **`THAT`**                                    │
│ (Questions)              │ (Nischit parinam poochna)   │ • *Do you doubt THAT he is honest?*           │
│                          │                             │ • *Can you have any doubt THAT you are wrong?*│
└──────────────────────────┴─────────────────────────────┴───────────────────────────────────────────────┘
```

---

### 🔍 Deep Analysis with Solved Class Examples:
1. *The directors doubt _______ the new machinery is really necessary.*
   - **Nature**: Positive (Affirmative) sentence → Directors ko shak (uncertainty) hai.
   - **Correct Conjunction**: **IF** ya **WHETHER** ✅ (*The directors doubt if/whether the new machinery is really necessary*).
   - *(Note: 'THAT' lagana galat hoga kyunki affirmative me 'that' nischit result batata hai)*.
2. *Her father was doubtful _______ one of his colleagues was involved in the embezzlement.*
   - **Nature**: Affirmative → Father doubtful hai.
   - **Correct Conjunction**: **IF** ya **WHETHER** ✅ (*doubtful whether one of his colleagues was involved...*).
3. *I do not doubt _______ Tanu will marry him.*
   - **Nature**: Negative (*do not doubt*) → Speaker ko 100% bharosa hai, koi doubt nahi hai!
   - **Correct Conjunction**: **THAT** ✅ (*I do not doubt that Tanu will marry him*).
4. *Can you have any longer doubt _______ you are mistaken?*
   - **Nature**: Interrogative question → Certainty context.
   - **Correct Conjunction**: **THAT** ✅ (*doubt that you are mistaken*).

## 5. The Advanced "IF" vs. "WHETHER" Dilemma

Aamtaur par students sochte hain ki Affirmative me `IF` aur `WHETHER` interchangeable hain. Lekin Tarun Grover sir ne iska **Secret Exam Rule** samjhaya:

```
                         ┌────────────────────────────────────────┐
                         │         "IF" vs. "WHETHER" RULE        │
                         └───────────────────┬────────────────────┘
                                             │
               ┌─────────────────────────────┴─────────────────────────────┐
               ▼                                                           ▼
     【 "IF" (Single Conditional) 】                             【 "WHETHER ... OR" (Correlative Pair) 】
     • Iska 'OR' ya 'OR NOT' ke sath koi                         • Jab sentence ke aage `OR` ya `OR NOT`
       correlative joda NAHI hota.                                 diya ho, to wahan **SIRF "WHETHER"** aayega!
     • *I doubt IF India will win the match.* ✅                   • Wahan "IF" lagana 100% GALAT hai!
       (No 'or not' in the sentence)                               • *I doubt WHETHER India will win OR NOT.* ✅
```

---

### 🎯 The "OR / OR NOT" Trap:
- *Sentence A*: *I doubt **if** India will win the match.* ✅ *(Dono sahi: if / whether)*.
- *Sentence B*: *I doubt **whether** India will win the match **or not**.* ✅ *(Only whether is correct!)*.
- *Sentence B (Error)*: *I doubt **if** India will win the match **or not**.* ❌  
  → **Reason**: `If ... or not` English grammar me invalid pair hai. Hamesha **`Whether ... or`** hi correlative pair hota hai!

#### Class Exam Question:
*Economists doubt _______ interest rates will fall in the near future **or not**.*
- Blank ke baad aage dekho → **"OR NOT"** maujood hai!
- Isliye yahan `if` bilkul nahi aa sakta → Correct Answer: **WHETHER** ✅.

## 6. Reason Conjunctions: "Because / Since / As"

Tarun Grover sir ka **"Reason Already Given" Rule**:

```
┌────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│                        THE "NO SO / THEREFORE / THUS" REDUNDANCY RULE                                  │
├────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│ Jab sentence `BECAUSE`, `SINCE`, ya `AS` se shuru hota hai, to kaaran (REASON) pehle hi spasht ho      │
│ chuka hota hai. Isliye aage aane wale result clause me `SO`, `THEREFORE`, `THUS`, ya `HENCE` lagana    │
│ **SUPERFLUOUS (अनावश्यक)** hota hai!                                                                   │
│                                                                                                        │
│ Formula: `Because / Since / As + Clause 1 , Clause 2`   (Sirf COMMA aayega, NO SO/THEREFORE!)          │
└────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

---

### 📝 Step-by-Step Solved Exam Sentences:
1. *Error*: *Because he was ill, **so** he could not attend the class.* ❌  
   → *Correction*: *Because he was ill, **he could not attend** the class.* ✅
2. *Error*: *Because he had been bedridden for more than two months, **therefore** you cannot force him to work.* ❌  
   → *Correction*: *Because he had been bedridden for more than two months, **you cannot force him** to work.* ✅
3. *Error*: *Since everybody knows each other, **so** there is no need for introductions.* ❌  
   → *Correction*: *Since everybody knows each other, **there is no need** for introductions.* ✅
4. *Error*: *As he was very supportive during our period of struggle and strife, **so** we should help him.* ❌  
   → *Correction*: *As he was very supportive during our period of struggle and strife, **we should help him**.* ✅
5. *Error*: *Since everything can be done from home with computers and telephones, **so** there is no need to dress up for work.* ❌  
   → *Correction*: *Since everything can be done from home..., **there is no need** to dress up for work.* ✅
6. *Error*: *Because breathing is something we do automatically, **so** it is an involuntary reaction.* ❌  
   → *Correction*: *Because breathing is something we do automatically, **it is** an involuntary reaction.* ✅

## 7. "Because" vs. "Because of"

Ek student ne live class me poocha: *"Sir, Because aur Because of me kya difference hai?"*

| Word | Part of Speech | What follows it? | Example Sentence |
| :--- | :--- | :--- | :--- |
| **Because** | **Conjunction** | **Complete Clause** (`Subject + Verb`) | • *Because **I was ill** (Sub + Verb), I could not attend the class.* ✅ |
| **Because of** | **Preposition** | **Noun / Pronoun / Noun Phrase** (No finite verb) | • *Because of **my illness** (Noun phrase), I could not attend the class.* ✅ |

- *Error*: *Because of I was ill, I stayed home.* ❌ → *Because I was ill...* ✅
- *Error*: *Because my illness, I stayed home.* ❌ → *Because of my illness...* ✅

## 8. Correlative Conjunctions & The Principle of Parallel Construction

Yeh Conjunction chapter ka **SABSE BADA aur SABSE IMPORTANT concept** hai, jahan se 80% error-spotting questions bante hain:

### 🔗 Core Correlative Pairs:
- `Either ... or` (या तो ... या)
- `Neither ... nor` (न तो ... न ही)
- `Not only ... but also` (न केवल ... बल्कि भी)
- `Both ... and` (दोनों ... और)
- `Whether ... or` (चाहे ... या)

---

### ⚖️ The Principle of Parallel Construction (समानांतर संरचना का नियम):
> **Golden Rule**: Jo Part of Speech ya Grammatical Unit doosre connector (`but also`, `or`, `nor`, `and`) ke theek baad aati hai, WAHI SAME Part of Speech pehle connector (`not only`, `either`, `neither`, `both`) ke theek baad aani chahiye!

$$\mathbf{First\ Connector\ +\ [X]\ \ \ \ \ \ \ \ Second\ Connector\ +\ [X]}$$

```
If Second Connector is followed by:          Then First Connector MUST be followed by:
• Noun                                 ───►  • Noun
• Verb                                 ───►  • Verb
• Adjective                            ───►  • Adjective
• Prepositional Phrase                 ───►  • Prepositional Phrase
```

---

### 🎯 Deep Solved Examples from Class:

#### Example 1: Object Parallelism (`Not only ... but also`)
- *Question Sentence*: *Not only did he criticize the party's policies, but also the leader's personal matters.* ❌
- **Tarun Grover Sir ka Analysis**:
  - Yahan do cheezon ko relate kiya ja raha hai:
    1. *The party's policies* (Noun Phrase - Object 1)
    2. *The leader's personal matters* (Noun Phrase - Object 2)
  - Verb *criticize* dono ke liye common hai (usne dono ko criticize kiya).
  - Sentence ke aage dekho: `but also` ke baad kya hai? → *the leader's personal matters* (Noun Phrase).
  - To `not only` ke baad bhi *the party's policies* (Noun Phrase) aana chahiye, na ki verb!
  - Jab `not only` sentence ke beech me aayega, to shuru ka Inversion (`did he criticize`) normal assertive ban jayega → `He criticized`!
- **Correct Sentence**:  
  $$\mathbf{He\ criticized\ not\ only\ the\ party's\ policies\ but\ also\ the\ leader's\ personal\ matters.\ ✅}$$

---

#### Example 2: Verb Parallelism (`Either ... or`)
- *Question Sentence*: *In the fall, Philip either will start classes at the community college as his mother wishes, or join the navy as his father wants.* ❌
- **Tarun Grover Sir ka Analysis**:
  - Sentence me Philip ke samne do actions (Verbs) hain:
    1. Action 1: *start classes at the community college*
    2. Action 2: *join the navy*
  - Look after `or`: `or` ke theek baad kya hai? → Verb **`join`**!
  - Isliye `either` ke baad bhi Verb **`start`** aana chahiye (modal *will* pehle aana chahiye)!
- **Correct Sentence**:  
  $$\mathbf{In\ the\ fall,\ Philip\ will\ either\ start\ classes...\ or\ join\ the\ navy...\ ✅}$$

---

#### Example 3: Adjective + Preposition Parallelism (No Error Case)
- *Question Sentence*: *Most of the popular tele-serials are not only illogical in their story line, but also crude in their representation.*
- **Tarun Grover Sir ka Analysis**:
  - Look after `not only`: `illogical` (Adjective) + `in their story line` (Prep phrase).
  - Look after `but also`: `crude` (Adjective) + `in their representation` (Prep phrase).
  - Dono taraf structure 100% identical aur parallel hai!
- **Verdict**: **NO ERROR (100% Correct Sentence!)** ✅

---

#### Example 4: Infinitive Parallelism (`Both ... and`)
- *Question Sentence*: *The funds were not only available to watch, but also to discuss.* ❌
- **Correction**: *The funds were available **both to watch and to discuss**.* ✅  
  *(Dono taraf `to + V1` infinitives perfectly balance ho rahe hain).*

## 9. "Seldom or never" vs. "Seldom if ever" & Inversion Rules

Yeh point exam ka **sabse lethal trap** hai jahan aksar acche-acche students galti kar dete hain:

```
┌────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│                               SELDOM PAIRS MASTER MATRIX                                              │
├───────────────────────────────────┬────────────────────────────────────────────────────────────────────┤
│ VALID / CORRECT PAIRS ✅          │ INVALID / EXAM ERROR PAIRS ❌                                      │
├───────────────────────────────────┼────────────────────────────────────────────────────────────────────┤
│ 1. **`Seldom OR never`** ✅        │ • `Seldom OR ever` ❌ (Wrong combination!)                         │
│    (शायद ही कभी या कभी नहीं)      │                                                                    │
│ 2. **`Seldom IF ever`** ✅         │ • `Seldom IF never` ❌ (Wrong combination!)                        │
│    (शायद ही कभी, यदि कभी हुआ भी) │                                                                    │
└───────────────────────────────────┴────────────────────────────────────────────────────────────────────┘
```

---

### 🔁 The Inversion Rule with Seldom:
- `Seldom` ek **Semi-Negative Adverb** hai (Hardly, Scarcely, Barely, Never ki tarah).
- **Rule**: Jab `Seldom or never` ya `Seldom if ever` sentence ke **SHURU (Beginning)** me lagaya jata hai, to sentence me **NEGATIVE INVERSION** hota hai (yaani Subject se pehle Auxiliary / Helping Verb aati hai)!

$$\mathbf{Seldom\ or\ never\ /\ Seldom\ if\ ever\ +\ Auxiliary\ Verb\ +\ Subject\ +\ Main\ Verb}$$

#### Class Examples & Inversion Analysis:
1. *Normal Placement (No Inversion)*:
   - *He has seldom or never written to me.* ✅ (Helping verb aur Main verb ke beech me normal placement).
2. *Beginning Placement (Inversion Mandatory)*:
   - *Error*: *Seldom or never there was any training or instruction in such tactics.* ❌  
   - *Correction*: *Seldom or never **was there** any training or instruction in such tactics.* ✅ (Helping verb *was* subject *training* se pehle aayi!).
3. *Sentence*: *These goods are made for export and **seldom if ever** sold in this country.* ✅
   - *Seldom if ever* is 100% grammatically valid! (No Error).

## 10. High-Frequency Fixed Conjunction Pairs & Inversion Review

Tarun Grover sir ne lecture ke ant me sabhi essential fixed conjunction pairs ka quick revision karwaya:

| Conjunction Pair | Inversion Rule | Key Restriction / Prohibited Words | Example Sentence |
| :--- | :--- | :--- | :--- |
| **Hardly ... WHEN / BEFORE** | Sentence shuru hone par Inversion (`Hardly had + S + V3`) | Never use **`THAN`** or **`THEN`** ❌ | • *Hardly had I entered the room **when** the phone rang.* ✅ |
| **Scarcely ... WHEN / BEFORE** | Inversion mandatory | Never use **`THAN`** ❌ | • *Scarcely had she finished speaking **when** tears rolled down.* ✅ |
| **No sooner ... THAN** | Inversion (`No sooner had + S + V3` / `did + S + V1`) | Never use **`WHEN`** or **`THEN`** ❌ | • *No sooner did the bell ring **than** the students rushed out.* ✅ |
| **Although / Though ... YET** | Normal structure | Never use **`BUT`** ❌ (Comma ya Yet lagao) | • *Although he worked hard, **yet** he failed.* ✅ |
| **Between ... AND** | Normal structure | Never use **`TO`** ❌ | • *The meeting will take place **between** 2:00 PM **and** 4:00 PM.* ✅ |
| **From ... TO** | Normal structure | Never use **`AND`** ❌ | • *The exhibition is open **from** 10:00 AM **to** 6:00 PM.* ✅ |
| **As ... AS** | Normal structure | Affirmative aur Negative dono me valid | • *He is **as tall as** his brother.* ✅ |
| **So ... AS** | Normal structure | Strictly **Negative sentences** me valid | • *He is not **so intelligent as** his sister.* ✅ |
| **Such ... THAT** | Result / Consequence | Darshata hai ki kaisa parinam nikla | • *It was **such** a cold night **that** the water froze.* ✅ |

## 11. Master Practice Question Bank

Tarun Grover sir ke lecture ke sabhi questions ka detailed step-by-step Hindi reasoning ke sath analysis:

---

### 📝 Question 1:
**Question**: *Suppose if (A) / you become a Bank PO (B) / in the next few months, (C) / what will you do next? (D) / No Error (E)*
- **Error**: Part (A)
- **Explanation**: `Suppose` aur `If` dono conditional conjunctions hain aur dono ka meaning same hota hai. Dono ko ek sath use karna superfluous (redundant) hai. Ya to `Suppose` use karo ya `If` → **"Supposing you become"** ya **"If you become"**.

---

### 📝 Question 2:
**Question**: *The teacher warned the students, (A) / "Run fast lest (B) / you will miss (C) / the morning assembly." (D) / No Error (E)*
- **Error**: Part (C)
- **Explanation**: `Lest` ke sath mandatory pair **`SHOULD`** ka banta hai (`will/may/might` nahi aa sakta) → **"you should miss"**.

---

### 📝 Question 3:
**Question**: *Walk carefully lest (A) / you should not slip (B) / on the wet pavement. (C) / No Error (D)*
- **Error**: Part (B)
- **Explanation**: `Lest` ka matlab hi hota hai *"taaki na / aisa na ho ki"*. Isme negative sense pehle se samahit hai, isliye iske sath `not` lagana strictly prohibited hai → **"you should slip"**.

---

### 📝 Question 4:
**Question**: *The directors doubt that (A) / the newly acquired machinery (B) / will increase production capacity. (C) / No Error (D)*
- **Error**: Part (A)
- **Explanation**: Affirmative (positive) sentence me `Doubt` ke sath `THAT` nahi balki `IF` ya `WHETHER` lagta hai kyunki yeh uncertainty darshata hai → **"The directors doubt if / whether"**.

---

### 📝 Question 5:
**Question**: *Her father was doubtful that (A) / one of his closest colleagues (B) / was secretly involved in the embezzlement. (C) / No Error (D)*
- **Error**: Part (A)
- **Explanation**: Affirmative sentence me `Doubtful` ke sath `IF` ya `WHETHER` aayega → **"was doubtful whether one of his closest colleagues"**.

---

### 📝 Question 6:
**Question**: *I do not doubt if (A) / Tanu will marry (B) / the boy of her choice. (C) / No Error (D)*
- **Error**: Part (A)
- **Explanation**: Negative sentence (*do not doubt*) me speaker ko koi shak nahi hai (certainty hai), isliye yahan `THAT` aayega → **"I do not doubt that Tanu will marry"**.

---

### 📝 Question 7:
**Question**: *Can you have any longer doubt if (A) / you are completely mistaken (B) / regarding his honesty? (C) / No Error (D)*
- **Error**: Part (A)
- **Explanation**: Interrogative sentence me `Doubt` ke sath `THAT` lagta hai → **"doubt that you are completely mistaken"**.

---

### 📝 Question 8:
**Question**: *Economists doubt if (A) / interest rates will fall (B) / in the near future or not. (C) / No Error (D)*
- **Error**: Part (A)
- **Explanation**: Jab aage clause me **`OR NOT`** diya ho, to `IF` ka prayog nahi kiya ja sakta; sirf correlative pair **`WHETHER ... OR NOT`** hi valid hota hai → **"Economists doubt whether interest rates will fall... or not"**.

---

### 📝 Question 9:
**Question**: *Because he had been bedridden (A) / for more than two months, (B) / therefore you cannot force him (C) / to do extra physical work. (D) / No Error (E)*
- **Error**: Part (C)
- **Explanation**: `Because` se shuru hone wale reason clause ke baad main clause me `therefore / so / thus` lagana superfluous hai → Remove **"therefore"**.

### 📝 Question 10:
**Question**: *Since everybody knows each other (A) / in this small community, (B) / so there is no need (C) / for formal introductions. (D) / No Error (E)*
- **Error**: Part (C)
- **Explanation**: `Since` ke sath `so` ka prayog nahi hota. Sirf comma lagta hai → Remove **"so"**.

### 📝 Question 11:
**Question**: *As he was very supportive (A) / during our period of struggle and strife, (B) / so we must extend (C) / all possible help to him. (D) / No Error (E)*
- **Error**: Part (C)
- **Explanation**: `As` reason clause me aane par result clause me `so` nahi lagta → Remove **"so"**.

### 📝 Question 12:
**Question**: *Not only did he criticize (A) / the political party's economic policies, (B) / but also the party leader's (C) / personal financial matters. (D) / No Error (E)*
- **Error**: Part (A)
- **Explanation**: Parallel construction error. `but also` ke baad noun phrase (*the party leader's personal matters*) hai, isliye `not only` bhi object (*the party's policies*) se pehle aana chahiye → **"He criticized not only the political party's economic policies but also..."**.

### 📝 Question 13:
**Question**: *In the coming autumn, Philip either (A) / will start classes at the college (B) / or join the naval forces (C) / to serve the nation. (D) / No Error (E)*
- **Error**: Part (A) / (B)
- **Explanation**: `or` ke baad verb *join* hai, isliye `either` bhi verb *start* se theek pehle aana chahiye → **"Philip will either start classes... or join"**.

### 📝 Question 14:
**Question**: *Most of the popular television serials (A) / are not only illogical in their plot, (B) / but also crude in their presentation. (C) / No Error (D)*
- **Error**: Part (D) - **NO ERROR**
- **Explanation**: `not only` ke baad *illogical in their plot* (Adj + Prep phrase) hai aur `but also` ke baad *crude in their presentation* (Adj + Prep phrase) hai. Dono taraf grammatical symmetry perfectly maintain hai.

### 📝 Question 15:
**Question**: *Seldom or ever (A) / have I witnessed such (B) / extraordinary courage in the face of danger. (C) / No Error (D)*
- **Error**: Part (A)
- **Explanation**: `Seldom or ever` koi valid pair nahi hota. Sahi pair ya to **`Seldom or never`** hota hai ya **`Seldom if ever`** hota hai → **"Seldom or never"** ya **"Seldom if ever"**.

### 📝 Question 16:
**Question**: *Seldom or never there was (A) / any proper training or instruction (B) / provided for recruits. (C) / No Error (D)*
- **Error**: Part (A)
- **Explanation**: Jab `Seldom or never` sentence ke shuru me aata hai, to negative inversion hota hai (Auxiliary verb subject se pehle aati hai) → **"Seldom or never was there any proper training"**.

### 📝 Question 17:
**Question**: *These specialized luxury items (A) / are manufactured exclusively for export (B) / and seldom if ever sold locally. (C) / No Error (D)*
- **Error**: Part (D) - **NO ERROR**
- **Explanation**: `Seldom if ever` bilkul sahi idiomatic pair hai, aur sentence ke beech me hone ke karan inversion ki zaroorat nahi hai.

### 📝 Question 18:
**Question**: *No sooner did the train arrive (A) / at the platform (B) / when the passengers rushed (C) / to board the compartments. (D) / No Error (E)*
- **Error**: Part (C)
- **Explanation**: `No sooner` ke sath correlative pair **`THAN`** hota hai (`when` nahi) → **"than the passengers rushed"**.

### 📝 Question 19:
**Question**: *The official discussion will take place (A) / between 10:00 AM to 1:00 PM (B) / in the conference room. (C) / No Error (D)*
- **Error**: Part (B)
- **Explanation**: `Between` ke sath hamesha **`AND`** lagta hai (`to` nahi) → **"between 10:00 AM and 1:00 PM"**.

### 📝 Question 20:
**Question**: *Although he faced severe financial hardships (A) / during his college days, (B) / but he never gave up his ambitions. (C) / No Error (D)*
- **Error**: Part (C)
- **Explanation**: `Although / Though` ke sath `BUT` lagana prohibited hai. Sahi connector **`YET`** ya sirf ek comma hota hai → **"yet he never gave up"** ya **", he never gave up"**.

## 12. Quick Revision Summary (Exam Cheat Sheet)

| Concept / Keyword | Quick Formula & Rule |
| :--- | :--- |
| **Suppose vs. If** | Never use together! Either use `Suppose` OR `If` (*Suppose you win...*) |
| **Lest ... Should** | `Lest + Subject + SHOULD + V1` \| Strictly **NO "NOT"** (Negative inherent) |
| **Doubt in Affirmative** | Positive sentence → **`IF / WHETHER`** (*I doubt if he will pass*) |
| **Doubt in Negative/Int.**| Negative / Question → **`THAT`** (*I do not doubt that he will pass*) |
| **If vs. Whether Trap** | If **`OR / OR NOT`** is present → **`WHETHER` is mandatory**! (`If` is prohibited) |
| **Because / Since / As** | Never use `so, therefore, thus, hence` in the result clause! (Just use a comma) |
| **Because vs. Because of**| `Because + Subject + Verb` (Clause) \| `Because of + Noun Phrase` (Preposition) |
| **Parallel Construction** | Part of speech after `but also/or/nor/and` = Part of speech after `not only/either/neither/both` |
| **Seldom Pairs** | **`Seldom OR never`** ✅ \| **`Seldom IF ever`** ✅ \| `Seldom or ever` ❌ \| `Seldom if never` ❌ |
| **Seldom Inversion** | When at sentence start → `Seldom or never + Aux Verb + Subject + Main Verb` |
| **Hardly / Scarcely** | Pair with **`WHEN / BEFORE`** (Never *than*) \| Inversion: `Hardly had + S + V3` |
| **No sooner** | Pair with **`THAN`** (Never *when/then*) \| Inversion: `No sooner had + S + V3` / `did + S + V1` |
| **Between vs. From** | **Between ... AND** \| **From ... TO** |
| **Although / Though** | Pair with **`YET`** or comma (Never *but*!) |
